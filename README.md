# 星间小记 · 可自由配色的本机写作空间

右上角的「调色」可选择六套预设或自由输入颜色。点击「写一篇」进入写作台，无需修改网页代码。

## 颜色与材质

强调色、背景、文字颜色均可自由调整，文字对比度自动校正。透明度、虚化、明暗与动态可独立控制；轻量模式关闭模糊与动效，页面也尊重系统的减少动态效果偏好。配色可单独导入导出 JSON，自动保存在当前浏览器，整库备份也包含配色。

## 写作

- Markdown：支持标题、列表、表格、引用、代码块、链接和混排数学公式。工具栏辅助插入，实时预览。
- TeX：支持常见分式、求和、矩阵等数学排版；不是完整 LaTeX 文档编译器，不编译任意宏包或生成排版 PDF。
- HTML：正文与样式在隔离区域内预览；脚本、表单及主动嵌入被禁用，避免影响博客或草稿。原始内容可导出为标准 HTML 文件。
- 导入 `.md`、`.markdown`、`.tex`、`.html`、`.txt`（UTF-8），或整库 JSON 备份。

保存后，勾选「显示在本机首页」的文章会出现在示例文章前，并参与分类与搜索。示例文章可隐藏。

## 保存与备份

内容只保存在当前浏览器、当前网站地址下，不跨设备同步，也不会把新文章发布给其他访问者。清理网站数据、使用无痕模式、换浏览器或换网址后，旧草稿可能不可用。请定期导出整库 JSON；也可导出单篇原格式文件。

导入备份采用合并方式，保留已有文章。存储受限或空间不足会显示错误，请根据保存状态确认内容已经落盘。

## 本地运行

在项目目录运行 `python -m http.server 4173 --directory dist`，打开 `http://localhost:4173`。建议使用本地服务器，浏览器对直接双击 `file://` 下的存储行为不一致。

`dist` 是完整静态网站，所有脚本、数学字体、插画均为本地资源。渲染依赖按需加载，首页无需先加载公式引擎。

## 文件说明

- `dist/index.html`、`style.css`：首页基础结构与样式。
- `dist/theme.js`、`theme.css`：主题与玻璃材质。
- `dist/studio.js`、`studio.css`：本机文稿管理与编辑器。
- `dist/renderer.js`、`reader-content.css`、`vendor/`：Markdown、公式、HTML 渲染。
- `dist/app.js`、`workspace.css`：文章列表、搜索、阅读器与编辑器连接。
- `dist/assets/`：优化插画与站标。

插画使用内置 ImageGen 生成，提示词保存于 `art-direction.txt`，画面角色不代表作者身份。
